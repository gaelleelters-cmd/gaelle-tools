Mail Mass

Mail merge from Excel into your Outlook — works for everyone on Windows with Outlook desktop. Each person sends from their own Outlook.

Before you send (one-time per PC)

  1. Use Windows with Outlook desktop open.
  2. Download and open Start-MailMassHelper.vbs — allow it if Windows asks.
  3. When the status below says connected, click Send with Outlook on this page.

Checking Outlook helper…

This helper stays on your computer only. It never sends through someone else’s Outlook. Every public user installs the same helper on their own PC.
